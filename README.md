# Lullaby Family — Medien

Bilder und Videos für die Instagram-Beiträge.

Dieses Repository ist **öffentlich**, damit Instagram die Dateien laden
kann. Es enthält ausschließlich Material, das ohnehin auf Instagram
veröffentlicht wird.

Gesteuert wird alles aus `lullaby-family-automat` (privat).

## higgsfield-referenz/

Textfreie Fassungen bereits veröffentlichter Titelbilder (aus
`lullaby-family-automat/assets/titel/`). Sie dienen als Vorlagen, die
Higgsfield per direktem Link lädt, um daraus Animationen zu erzeugen.
Der Instagram-Automat greift nicht auf diesen Ordner zu.
